## RwkvTrie

`RwkvTrie` implements RWKV World's greedy longest match over UTF-8 bytes. Its
vocabulary keys use the Hugging Face ByteLevel alphabet, so the config names no
normalizer and no pre-tokenizer, and `ByteLevel` is the only other component:

```json
{
  "version": "2.0",
  "normalizer": null,
  "pre_tokenizer": null,
  "decoder": { "type": "ByteLevel" },
  "model": { "type": "RwkvTrie", "vocab": { "<ByteLevel spelling>": 1 } }
}
```

There is no model class to construct under `tokenizers.models`: the model is read
from a canonical `tokenizer.json`.

```python
from tokenizers import Tokenizer

tokenizer = Tokenizer.from_file("tokenizer.json")
encoding = tokenizer.encode("Hello, 世界", add_special_tokens=False)
assert tokenizer.decode(encoding.ids) == "Hello, 世界"
```

Token ID 0 is retained for explicit end-of-document boundaries but is never
produced by normal text encoding. BlinkDL's Python-literal vocabulary text file
can be converted to ByteLevel JSON with:

```bash
python temp/convert_rwkv_vocab.py rwkv_vocab_v20230424.txt rwkv-vocab.json
```
